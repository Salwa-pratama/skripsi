1. Ringkasan Eksekutif & Filosofi Arsitektur (Offloading)

Dalam proyek Computer Vision menggunakan mikrokontroler berbiaya murah, strategi terbaik adalah Edge Streaming & Host Processing (Offloading):

  • Peran ESP32-S3: Bertindak sebagai Lightweight Streaming Device murni. ESP32 hanya bertugas menginisialisasi kamera, membaca frame buffer, mengompres JPEG secara ringan, dan memancarkan data via Wi-Fi secepat mungkin tanpa dibebani komputasi visual yang membuat chip panas.
  • Peran Server Python (Host): Bertindak sebagai Visual Processing Engine. Laptop/Server memiliki resource komputasi ratusan kali lebih kuat untuk melakukan denoising, koreksi backlight (CLAHE), penajaman kontur tangan (Sharpening), dan tracking 21 titik sendi jari tangan via MediaPipe/AI.

2. Analisa Masalah Citra Kamera OV5640 & Solusinya

Gejala Masalah Akar Penyebab (Root Cause) Solusi Rekayasa (Hardware & Firmware)
Video Patah-Patah (~2 FPS) Terdapat fungsi vTaskDelay(pdMS_TO_TICKS(500)) di file app.httpd.cpp yang menahan pengiriman frame selama 0.5 detik per frame. Ubah menjadi vTaskDelay(pdMS_TO_TICKS(1)). Naikkan clock kamera ke xclk = 20000000 (20 MHz) dan gunakan buffer ganda (fb_count = 2). FPS melonjak ke 25-30+ FPS.
Semburat Merah / Magenta di Tepi Kanan (>50°C) Thermal Gradient & Dark Current: Chip prosesor dan regulator daya di sisi kanan board memancarkan panas. Sensor silikon CMOS menangkap panas ini sebagai sinyal warna merah/ungu, diperparah ketiadaan fisik filter IR (Infrared). 1. Renggangkan kabel pita kamera agar tidak menempel di plat besi ESP32.
2. Turunkan clock CPU ke 160 MHz (suhu chip turun ke 48-52°C).
3. Batasi penguatan sensor dengan s->set_gainceiling(s, GAINCEILING_2X).
Wajah / Objek Gelap Gulita (Black Crush) Backlight Overpower: Lampu plafon atau jendela di belakang objek sangat silau. Fitur AEC (Auto Exposure Control) meredupkan kamera secara otomatis agar latar tidak overexposed, sehingga objek di depan menjadi siluet hitam. 1. Naikkan s->set_brightness(s, 1) dan s->set_ae_level(s, 1).
2. Turunkan s->set_contrast(s, -1).
3. Terapkan algoritma CLAHE di server Python.
Lengkungan Hitam di Tepi Kiri (Vignetting) Ketika s->set_lenc(s, 0) dinonaktifkan pada resolusi CIF, penurunan cahaya alami pada sudut lensa cembung (optical vignetting) tidak lagi dikompensasi secara digital. Aktifkan kembali koreksi lensa internal: s->set_lenc(s, 1). Jika ingin bidang pandang terbebas dari artefak sudut lensa, gunakan resolusi FRAMESIZE_QVGA (320x240).
Wajib Menekan Tombol EN/RST Setiap Selesai Flash Driver USB-CDC pada ESP32-S3 tidak otomatis memicu hard reset pasca-unggah firmware oleh esptool. Tambahkan konfigurasi upload_flags = --after=hard_reset di file platformio.ini dan sistem auto-restart via kode jika inisialisasi sensor gagal.

B. File: src/func/camera_config.cpp

// 1. Inisialisasi Hardware
config.xclk_freq_hz = 20000000;         // 20 MHz XCLK (Tinggi & Mulus)
config.frame_size   = FRAMESIZE_CIF;     // 400x296 (atau FRAMESIZE_QVGA 320x240)
config.pixel_format = PIXFORMAT_JPEG;
config.grab_mode    = CAMERA_GRAB_LATEST; // Buang frame basi, selalu ambil frame baru
config.fb_location  = CAMERA_FB_IN_PSRAM;
config.jpeg_quality = 22;                // Kompresi optimal, file ringan via WiFi
config.fb_count     = 2;                 // Double buffer

// 2. Konfigurasi Sensor Kamera (Permanen setelah esp_camera_init)
sensor_t *s = esp_camera_sensor_get();
if (s != NULL) {
  s->set_framesize(s, FRAMESIZE_CIF);
  s->set_vflip(s, 1);                    // 1 = Balik vertikal
  s->set_hmirror(s, 1);                  // 1 = Balik horizontal
  s->set_denoise(s, 0);                  // 0 = Matikan filter denoise internal
  s->set_special_effect(s, 0);
  s->set_lenc(s, 1);                     // 1 = Aktifkan Lens Correction (Cegah hitam di tepi)
  s->set_brightness(s, 1);               // 1 = Boost kecerahan objek gelap
  s->set_contrast(s, -1);                // -1 = Redam kontras bayangan tajam
  s->set_gainceiling(s, GAINCEILING_2X); // 2X = Batasi gain agar tidak muncul noise merah termal
  s->set_bpc(s, 1);                      // 1 = Koreksi piksel rusak (hot pixels)
  s->set_wpc(s, 1);
}

ESP32 ini sengaja diset sangat ringan (dumb streaming) tanpa filter internal untuk menjaga suhu chip tetap dingin (~50°C). Oleh karena itu, saya ingin membuat script Python berkinerja tinggi menggunakan OpenCV, NumPy, dan MediaPipe Hands untuk menangkap stream tersebut dan melakukan preprocessing citra di sisi laptop/host tanpa membebani ESP32.

Tolong buatkan program Python lengkap, terstruktur, dan siap pakai dengan spesifikasi berikut:

1. VIDEO INGESTION:
   - Gunakan cv2.VideoCapture() untuk membaca MJPEG stream dari URL ESP32.
   - Buat thread terpisah (Video Threading) agar pembacaan frame tidak blocking dan latency/delay tetap 0 (realtime).

2. IMAGE ENHANCEMENT PIPELINE (Mengatasi Masalah Kamera Fisik):
   a. Mengatasi Wajah/Tangan Gelap (Backlight Compensation):
      Gunakan algoritma CLAHE (Contrast Limited Adaptive Histogram Equalization) pada kanal L (Luminance) dalam ruang warna LAB atau YCrCb untuk menerangkan tangan/wajah yang gelap secara dinamis tanpa membuat latar belakang putih/lampu menjadi silau.
   b. Mengatasi Noise Bintik-bintik Kamera Panas (Denoising & Smoothing):
      Terapkan cv2.bilateralFilter() agar noise bintik sensor OV5640 dihaluskan, tetapi garis kontur dan tepi jari tangan tetap terjaga tajam (edge-preserving).
   c. Mengatasi Semburat Merah/Magenta Akibat Thermal Noise:
      Lakukan auto white-balance digital ringan atau scaling channel merah (R) jika terdeteksi dominasi magenta di sudut frame.
   d. Penajaman Kontur Jari (Unsharp Masking):
      Terapkan filter konvolusi penajaman (sharpening kernel) agar batas jari tangan sangat tegas dan mudah dibaca AI.

3. AI HAND TRACKING (Google MediaPipe Hands):
   - Integrasikan MediaPipe Hands (mp.solutions.hands) pada frame yang sudah dipoles di atas.
   - Gambar kerangka 21 landmark sendi jari tangan dan bounding box secara realtime.
